# User Profile Formatter

A simple TypeScript project that formats a nested user object into useful values that can be displayed in an interface or returned from an API.

## What It Does

The project includes functions to:

* Get a user's full display name
* Get their location
* Get their contact information
* Check if their account is active
* Create a complete profile summary

## Concepts Practiced

* TypeScript interfaces
* Nested objects
* Function parameters and return types
* Template literals
* Object destructuring concepts
* Working with `null` values
* Returning objects from functions

## Example

```ts
createProfileSummary(user);
```

Returns a summary containing:

```text
displayName
location
contact
active
plan
```
